WEEKLY SERVICE SCHEDULE

Files:
- index.html: page layout
- style.css: styling
- script.js: calendar behavior and sample appointments

How to run:
1. Extract the ZIP file.
2. Open the weekly-service-schedule folder.
3. Double-click index.html to open it in Chrome.
4. Click + Add appointment to create a schedule item.
5. Click an existing appointment to edit or delete it.
6. Use the week arrows and search box to navigate/filter.

Appointments are saved in this browser using localStorage. They do not sync to other computers.
The initial sample appointments are examples inspired by the whiteboard photo; they are not a verified transcription.
